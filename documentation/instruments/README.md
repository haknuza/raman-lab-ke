# Local instrument documentation

Place the Avantes/AvaRaman manuals, their JSON conversions and the laboratory SOP
in this directory. The supplied files were moved here from the original
`DocumentsRegardingRammanSpectrography` folder.

Manuals and laboratory documents remain on the local machine and are excluded
from Git. This public repository contains the implementation and design notes,
not redistributed vendor PDFs or private laboratory source documents.

See `../../docs/RAMAN_SCANNER_PLAN.md` for the document inventory and engineering
notes. Obtain the applicable manuals and compatible SDK from Avantes for the
actual instrument model.
