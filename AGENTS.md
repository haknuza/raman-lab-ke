# Working on Raman Lab KE

## Keep the project README current

The user requests an ongoing record of the work in `README.md`. When a task
changes implemented behavior, component layout, setup or run commands, hardware
integration status, validation results or the next milestones, update the README
as part of that same change.

- Keep completed work, current capabilities and pending work distinct.
- Update the last-updated date when the README changes, using the user's local
  date. Append dated progress entries for notable milestones; group same-day
  entries when that improves readability.
- Record only checks actually performed, including their scope and material
  limitations. Do not imply a previously recorded check was rerun.
- Distinguish simulated data and software tests from physical measurements.
- Preserve useful usage instructions and links when adding progress notes.
- Keep supplied vendor/laboratory documents, local credentials, machine-specific
  configuration and run outputs excluded from the public repository.

These documentation instructions do not authorize physical hardware operations.
Follow applicable component instructions, including `printer-control/AGENTS.md`,
for changes and validation in those components.
